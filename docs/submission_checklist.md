## 二、网盘目录结构

一个文件夹，命名为 `〔团队编号〕-AI+跨境电商-运价明镜-代码与数据`，目录如下：

```
〔团队编号〕-AI+跨境电商-运价明镜-代码与数据/
├── README.md                 复现说明（环境、安装、测试、生成测试集、组装与评分命令；重写为提交版）
├── pyproject.toml
├── requirements.txt
├── src/quoteguard/           源码
├── tests/                    单元测试
├── scripts/                  执行、补跑、冻结、估算、出图出表脚本
├── configs/                  models.yaml、rates.json
├── data/
│   ├── params/               参数快照与官方原始依据
│   ├── taskgen/              费用结构库、取值集合、合成登记库、参照下限（含 dev_v3）
│   ├── tasks/                dev、test 任务与面向模型的输入
│   ├── gold/                 dev、test 标准答案
│   └── seeds/                单元清单、盲标名单、匿名件、标签与裁决
├── docs/
│   ├── protocol/             冻结协议、冻结记录、预算估算、偏离记录
│   ├── plan/                 最终方案（提交版）、任务生成规格、方法实现规格、真实报价集规范
│   └── figures/              方案图（PNG、PDF、SVG）
├── runs/                     正式实验、思考组、预试验与第 0 步的原始记录，derived/ 下的组装与评分输出，spend_ledger.jsonl
├── demo/                     离线演示系统与截图
└── 提交材料/                  技术方案、PPT、佐证材料的 PDF 副本（与上传版本相同）
```

**不放入网盘的内容**

| 内容 | 原因 |
|---|---|
| reference/ | 上一个项目的参考代码，含其参赛材料生成脚本与赛事名称 |
| .claude/、CLAUDE.md、docs/CLOUD_SETUP.md、docs/CLOUD_KICKOFF.md | 开发环境与协作配置，含本机路径 |
| docs/plan/AIC_选题方案.md | 选题阶段的比较材料，提到其他高校作品与上一个项目 |
| docs/handover/ | 队友交接材料，含选取依据与复审要点，属于内部工作文件 |
| output/label_review_13/ | 复核包，复核结果导入 data/seeds/labels/ 后由标签文件取代 |
| PROJECT_LOG.md | 内部工作记录；过程证据由冻结记录、偏离记录与 runs/ 原始记录提供 |
| .git/ | 不放；如需证明时间线，另附 `git log --format='%h %ad %s' --date=iso` 导出文本，先按第三节检查 |
| 仓库外的原件、名称与网址对照表、登记库真实名称查询记录 | 匿名化要求 |

## 四、上传前最后核对

- 报告、PPT、视频、简介中的同一数字一致（决策正确率、micro-F1、每百票少付、成本）。
- 报告中的哈希与 docs/protocol/冻结记录.md 一致，`python scripts/freeze_protocol.py --check` 通过。
- 网盘内 `pytest` 全量通过；README 中的组装与评分命令能在新环境复现第五章表格。
- 技术方案 PDF 不超过 10 MB，视频不超过 300 MB 且时长在 3–5 分钟内。
- 网盘链接设为永久有效，链接写入提交表单。
