# 正式实验预算估算（2026-10-10）

估算方法与明细见 `runs/derived/budget_estimate_20261010/`（`scripts/estimate_budget.py`，离线，无模型调用）：用编排器对 dev 集 24 个任务建调用计划，按 48/24 外推；输入 token 按提示词字节数乘预试验实测的 token/字节比；点估计的输出 token 取预试验观测均值，上界取输出上限（M1 为 12000）与最大 token/字节比。价格取 `runs/pilot_inputs/rates.json`，美元按参数快照汇率 6.733 折算。

## 调用数

每个配置 M0 48、M1 48、抽取 238；转写每个视觉模型 74 次（共用视觉模型的转写只算一次）；ds_flash_think 的 M1 48 次；合计 2348 次。

## 估算的不确定性来源

- ds_pro、qwen_max 没有预试验观测，输出 token 取同类型其他配置的最大值。
- ds_flash_think 没有观测，思考输出按 M1 最大观测 7618 token 估计，实际可能更高；它的上界按输出上限 8000 计。
- 转写每个视觉模型只有 1 条观测。
